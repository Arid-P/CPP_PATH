## Checkpoint P3-1 Verification (CPP-01, CPP-02)

### Statements:
1. Preprocessing (`#include`) runs before the C++ compiler parses syntax or checks data types.
2. An object file (`.o`) generated by `g++ -c` is a text file containing human-readable assembly instructions.
3. The linker is responsible for resolving function calls to external libraries like `libstdc++` and assigning final memory addresses to produce the executable binary.
4. In C++, every program must contain at least one function named `main`, and its return type must be `int`.
5. The extraction operator `>>` with `std::cin` always requires input numbers to be separated by a comma (`,`).
6. In C++, single quotes `' '` and double quotes `" "` can be used interchangeably for single-character literals, just like in Python.
7. In Linux shells, typing an executable name without a leading path (like `sum` instead of `./sum`) looks for the binary exclusively in the current working directory.

### Student Answers (Verbatim):
`t, f, t, t, f, f, f`

### Grading & Notes:
- **Statement 1:** Correct. (Preprocessed text manipulation occurs before parsing and compilation).
- **Statement 2:** Correct. (`.o` contains binary machine code and symbol relocation tables, not human-readable assembly).
- **Statement 3:** Correct. (The linker's primary duty is symbol resolution and address layout).
- **Statement 4:** Correct. (`int main()` is the mandatory entry point).
- **Statement 5:** Correct. (`>>` skips whitespace—spaces, tabs, newlines; commas are not default separators).
- **Statement 6:** Correct. (`'a'` is a 1-byte `char`, `"a"` is a null-terminated string literal `const char[2]`).
- **Statement 7:** Correct. (Linux shells search `$PATH`; the current directory `.` is not searched by default).

**Result:** 7 / 7 Correct (100%). Checkpoint P3-1 verified.
